Speak into any machine. Keep the audio home.

Voca is free, open source voice typing for Linux, Mac, Windows, and phone. Hold a hotkey, talk, and the words land where your cursor is. Models run on your hardware. Nothing goes to a cloud account you never wanted.

The Voca apps

One idea, native apps per platform. Start with the machine you use every day.

  • Linux Stable

    VocaLinux

    System-wide offline dictation for real Linux desktops. whisper.cpp by default, Whisper and VOSK as options, Vulkan GPU acceleration, X11 and Wayland.

    Python · whisper.cpp · X11 · Wayland · 724★

    vocalinux.com GitHub
  • macOS Beta

    VocaMac

    Native menu bar app. Hold a hotkey, speak, text appears. WhisperKit and CoreML on Apple Silicon. Install with Homebrew or a DMG.

    Swift · WhisperKit · Apple Silicon · 75★

    vocamac.com GitHub
  • Windows Coming soon

    VocaWin

    Windows tray app with the same offline-first design. System-wide injection and GPU acceleration are planned. No cloud dependency.

    Offline-first · System tray · GPU planned

    vocawin.com GitHub
  • iOS · Android In development

    vocaphone

    Offline voice-to-text for phone. Speak, text appears. Same privacy bar as the desktop apps. Still early.

    Mobile · On-device STT

    GitHub
  • Server Early

    vocaserver

    Headless Voca server: set up once, run everywhere. For people who want one trusted local (or self-hosted) engine feeding several clients.

    Headless · Set up once

    GitHub

What does not change

Platforms differ. The deal does not.

Free, forever

No premium tiers, no accounts, no "free until we add a wall." Same open licenses you can read and ship with.

Offline first

Local engines process audio on the device. No usage telemetry for dictation. Remote servers are optional and only ones you configure.

Works where you type

Text goes into the focused field: browsers, IDEs, chat, terminals, office apps. Not locked to one editor.

Built in the open

Public under VocaHQ. Issues and PRs welcome on each project. Maintainer: @jatinkrmalik.

Where this is going

Longer term we want one setup that covers whatever you own: desktop plus phone, headless or interactive, mixed platforms. Real feature parity, not a different product on every OS.

  1. Now

    Desktop depth

    VocaLinux is stable and still shipping hard. VocaMac is in beta with Homebrew and a native Apple Silicon path. We keep hardening reliability, engines, and install paths.

  2. Next

    Windows and phone

    VocaWin moves from "coming soon" to something you can actually dictate with. vocaphone brings the same offline bar to iOS and Android.

  3. Later

    One setup, many clients

    vocaserver and shared patterns so a single trusted engine can feed the machines you already run. Project sites consolidate on vocahq.com over time.
