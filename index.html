What stays the same

Platforms differ. The contract does not.

Free, forever

No premium tiers, no accounts, no “freemium later.” Same open licenses you can audit and ship with.

Privacy / offline focus

Local engines process audio on-device. No telemetry, no usage analytics, no “phone home” for dictation.

Works where you type

System-wide injection into the focused field — browsers, IDEs, chat, terminals, office apps — not locked to one editor.

Built in the open

Maintained publicly under VocaHQ. Issues and PRs welcome on each project. Maintainer: @jatinkrmalik.

Where we’re headed

Longer term: set Voca up once and use it across whatever you own. Desktop plus phone, headless or interactive, mixed platforms — with real feature parity, not a different product every OS.

  1. Now

    Desktop depth

    VocaLinux stable and shipping hard; VocaMac in beta with Homebrew and native Apple Silicon path. Harden reliability, engines, and install experience.

  2. Next

    Windows + phone

    VocaWin moves from “coming soon” to usable offline dictation. vocaphone brings the same privacy bar to iOS and Android.

  3. Later

    One setup, many clients

    vocaserver and shared patterns so a single trusted engine can feed the machines you already run. Consolidate project sites on vocahq.com over time.
