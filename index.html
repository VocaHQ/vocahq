What does not change

Platforms differ. The deal does not.

Free, forever

No premium tiers, no accounts, no "free until we add a wall." Same open licenses you can read and ship with.

Offline first

Local engines process audio on the device. No usage telemetry for dictation. Remote servers are optional and only ones you configure.

Works where you type

Text goes into the focused field: browsers, IDEs, chat, terminals, office apps. Not locked to one editor.

Built in the open

Public under VocaHQ. Issues and PRs welcome on each project. Maintainer: @jatinkrmalik.

Where this is going

Longer term we want one setup that covers whatever you own: desktop plus phone, headless or interactive, mixed platforms. Real feature parity, not a different product on every OS.

  1. Now

    Desktop depth

    VocaLinux is stable and still shipping hard. VocaMac is in beta with Homebrew and a native Apple Silicon path. We keep hardening reliability, engines, and install paths.

  2. Next

    Windows and phone

    VocaWin moves from "coming soon" to something you can actually dictate with. vocaphone brings the same offline bar to iOS and Android.

  3. Later

    One setup, many clients

    vocaserver and shared patterns so a single trusted engine can feed the machines you already run. Project sites consolidate on vocahq.com over time.
